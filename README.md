# صندوق فروش کافه (Coffee Shop POS)

یک نرم‌افزار دسکتاپ ویندوزی ساده با پایتون و PyQt5 که منوی کافه را دقیقاً مطابق
تصویر شما به‌صورت گرید نمایش می‌دهد. با کلیک روی هر نوشیدنی، یک فروش برای آن
ثبت می‌شود و تعداد + قیمت واحد + مبلغ کل در یک فایل اکسل (به تفکیک هر روز)
ذخیره می‌گردد.

## امکانات

- **فونت اختصاصی**: فونت فارسی «وزیرمتن» (Vazirmatn) به‌صورت فایل داخل پروژه
  (`fonts/`) قرار داده شده و برنامه هنگام اجرا خودش لودش می‌کند. یعنی مهم
  نیست این فونت روی سیستم مشتری‌های شما نصب باشد یا نه — روی هر ویندوزی
  دقیقاً همین ظاهر را خواهد داشت.
- نمایش گرافیکی منو، دقیقاً مطابق طرح تصویر (۱۹ نوشیدنی).
- **تاریخ شمسی (جلالی)**: همه‌جای برنامه — عنوان صفحه، نام شیت‌های اکسل و
  گزارش‌ها — با تقویم هجری شمسی کار می‌کند (با کتابخانه `jdatetime`).
- کلیک روی هر نوشیدنی = ثبت یک فروش برای همان روز، با «قیمت پیش‌فرض» که در
  کادر زیر نام آن نوشیدنی نوشته‌اید.
- دکمه **«٪ فروش با قیمت دیگر»** زیر هر نوشیدنی: برای وقتی که می‌خواهید یک
  فروش خاص را با قیمت متفاوت (تخفیف، مهمان ویژه و غیره) ثبت کنید، بدون اینکه
  قیمت پیش‌فرض آن نوشیدنی برای فروش‌های بعدی تغییر کند. مثلاً اسپرسو را
  می‌توانید یک‌بار ۱۴۰، یک‌بار ۱۱۰ و یک‌بار ۱۰۰ بفروشید؛ هرکدام درست با همان
  قیمت در اکسل ثبت می‌شود.
- دکمه ↺ زیر هر نوشیدنی برای لغو آخرین فروش آن مورد (در صورت اشتباه کلیک
  کردن).
- امکان تنظیم/ویرایش قیمت پیش‌فرض هر نوشیدنی، مستقیماً در کادر زیر نام آن.
- دکمه **«📊 گزارش فروش»** پایین صفحه: یک روز خاص یا یک بازه‌ی تاریخی
  (مثلاً «۷ روز اخیر»، «۳۰ روز اخیر» یا «همه‌ی روزها») را انتخاب کنید و
  جدول تعداد و مبلغ فروش هر نوشیدنی در آن بازه را ببینید، به‌همراه مجموع
  کل. از همین پنجره می‌توانید گزارش را به‌صورت یک فایل اکسل جداگانه هم
  ذخیره کنید.
- دکمه **«➕ ثبت فروش فراموش‌شده»** پایین صفحه: اگر فراموش کردید فروشی را
  همان روز ثبت کنید (مثلاً امروز یادتان افتاد که دو روز پیش یک اسپرسو
  فروخته بودید)، از این دکمه می‌توانید تاریخ درست، نوشیدنی و قیمت را انتخاب
  کنید تا مستقیماً در شیت همان روز ثبت شود — بدون اینکه به شیت «امروز»
  دست بزند.
- ذخیره خودکار در `sales_data/sales.xlsx`؛ هر روز یک شیت جدید (با نام
  تاریخ شمسی) شامل:
  - یک بخش **خلاصه** در بالای شیت: تعداد و مبلغ کل فروش هر نوشیدنی (با
    فرمول محاسبه می‌شود، حتی اگر قیمت‌ها فرق داشته باشند) + ردیف «مجموع کل».
  - یک بخش **ثبت تک‌تک فروش‌ها** پایین‌تر: هر فروش با ساعت دقیق و قیمت واقعی
    همان فروش، به‌صورت جداگانه ثبت می‌شود؛ این یعنی هیچ اطلاعاتی گم نمی‌شود
    و می‌توانید هر زمان بررسی کنید چه چیزی با چه قیمتی فروخته شده.
- قیمت‌های پیش‌فرض در فایل `prices.json` ذخیره می‌شوند تا در اجرای بعدی
  برنامه از دست نروند.
- در صورت بستن و باز کردن مجدد برنامه در همان روز، تعداد فروش‌های ثبت‌شده
  از روی فایل اکسل بازیابی می‌شود.

## نحوه‌ی کار فایل اکسل (مهم)

فایل `sales_data/sales.xlsx` یک فایل واحد است که **برای هر روز، یک شیت
(Sheet) جداگانه** در آن ساخته می‌شود — نه اینکه سطرهای روز بعد زیر سطرهای
روز قبل در همان شیت اضافه شوند. یعنی:

- وقتی تاریخ روز عوض شود، برنامه به‌صورت خودکار یک شیت جدید با نام همان
  تاریخ (شمسی) می‌سازد.
- هیچ داده‌ای از روزهای قبل پاک یا بازنویسی نمی‌شود؛ همه‌ی شیت‌ها کنار هم در
  همان فایل باقی می‌مانند و می‌توانید هر زمان بین تب‌های پایین اکسل جابه‌جا
  شوید و شیت هر روز را جداگانه ببینید.
- بخش «گزارش فروش» داخل برنامه دقیقاً همین شیت‌ها را می‌خواند و برای بازه‌ی
  انتخابی شما با هم جمع می‌زند.

## نصب و اجرا (ویندوز / لینوکس / مک)

```bash
pip install -r requirements.txt
python main.py
```

## ساخت فایل اجرایی ویندوز (exe)

برای اینکه نرم‌افزار روی سیستم‌های دیگر بدون نیاز به نصب پایتون اجرا شود:

```bash
pip install pyinstaller
pyinstaller --noconfirm --windowed --name "CoffeeShopPOS" --icon=app_icon.ico ^
    --add-data "assets;assets" --add-data "fonts;fonts" main.py
```

خروجی در پوشه `dist/CoffeeShopPOS/` قرار می‌گیرد. فایل `CoffeeShopPOS.exe`
را اجرا کنید. توجه: پوشه‌های `assets` و `fonts` باید کنار فایل exe باشند (با
دستور بالا به‌صورت خودکار کپی می‌شوند). فایل `app_icon.ico` (آیکون برنامه)
باید کنار `main.py` باشد تا دستور بالا بتواند پیدایش کند.

اگر بعداً خواستید آیکون را عوض کنید: فایل `.ico` جدید خود را (ترجیحاً شامل
سایزهای ۱۶، ۳۲، ۴۸، ۱۲۸ و ۲۵۶ پیکسل در یک فایل) جایگزین `app_icon.ico` کنید
و دوباره دستور بالا را اجرا کنید. اگر آیکون در ویندوز اکسپلورر تغییر نکرد
(کش قدیمی نشان داده می‌شود)، پوشه‌های قبلی `build` و `dist` را پاک کنید و
دوباره بسازید، یا کش آیکون ویندوز را پاک/ری‌استارت کنید.

## ساختار فایل‌ها

```
coffee_pos/
├── main.py             # رابط گرافیکی (GUI) اصلی برنامه
├── app_font.py            # لود فونت اختصاصی (Vazirmatn) از پوشه fonts/
├── report_dialog.py         # پنجره‌ی گزارش فروش (بازه تاریخی / روز خاص)
├── backdate_dialog.py         # پنجره‌ی ثبت فروش برای یک روز دیگر (فروش فراموش‌شده)
├── date_utils.py               # تبدیل و نمایش تاریخ شمسی (jdatetime)
├── menu_data.py                   # لیست نوشیدنی‌ها، نام‌ها و چیدمان آن‌ها
├── excel_manager.py                 # منطق نوشتن/خواندن فایل اکسل و گزارش‌گیری
├── price_store.py                     # ذخیره و بازیابی قیمت‌ها (prices.json)
├── requirements.txt
├── app_icon.ico                          # آیکون برنامه/فایل exe (از عکس منو ساخته شده)
├── fonts/                                # فونت وزیرمتن (Vazirmatn UI) - OFL license
├── assets/                                # آیکون هر نوشیدنی (برش‌خورده از تصویر منو)
└── sales_data/
    └── sales.xlsx                          # فایل اکسل فروش (پس از اولین اجرا ساخته می‌شود)
```

## تغییر فونت در آینده

اگه بعداً خواستید فونت رو عوض کنید، کافیه:
1. فایل‌های `.ttf` فونت جدید را داخل پوشه‌ی `fonts/` بگذارید.
2. لیست `TTF_FILES` در فایل `app_font.py` را با نام فایل‌های جدید به‌روزرسانی
   کنید.

همه‌ی صفحات برنامه (پنجره‌ی اصلی و پنجره‌ی گزارش) به‌صورت خودکار فونت جدید را
استفاده خواهند کرد، چون همه از `app_font.APP_FONT_FAMILY` می‌خوانند.

## نکات

- اگر می‌خواهید نام نمایشی نوشیدنی‌ها یا چیدمان آن‌ها را تغییر دهید، کافی
  است فایل `menu_data.py` را ویرایش کنید.
- برای شروع یک دوره حسابداری جدید (مثلاً پاک کردن سوابق قدیمی)، به‌سادگی
  فایل `sales_data/sales.xlsx` را به مکان دیگری منتقل یا آرشیو کنید؛ برنامه
  به‌صورت خودکار فایل و شیت جدید می‌سازد.
